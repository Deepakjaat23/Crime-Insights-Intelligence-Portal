# 📊 Crime Insights & Intelligence Portal

The **Crime Insights & Intelligence Portal** is an advanced **Power BI dashboard** designed to analyze crime trends, hotspots, victim demographics, weapon usage, district insights, and time-based patterns. It transforms raw crime data into powerful, interactive visual insights.

---

## 🚀 Key Highlights
- 📍 Crime Hotspot Mapping using geo-coordinates  
- 🕒 Time Slot Analysis (Morning, Afternoon, Evening, Night)  
- 🔫 Weapon-Wise Crime Trends  
- 👥 Victim Age & Gender Demographics  
- 🏠 Premise & Area-wise Crime Distribution  
- 🧭 District-wise Crime Insights  
- 📈 Top Crime Categories (Part 1 & Part 2)  
- 📊 Clean, interactive, and user-friendly design  

---

## 🛠️ Dashboard Features

### **1. Crime Overview KPIs**
- Total number of crimes  
- Weapon-related cases  
- Solved vs. unsolved cases  
- Victim demographic summary  
- Major crime category breakdown  

### **2. Crime Hotspot Map**
Uses latitude and longitude values to display high-density crime areas.

### **3. Crime by Time Slot**
Categorizes crimes by time of occurrence to identify behavioral patterns.

### **4. Weapon Usage Analysis**
Shows the frequency of crimes based on weapon types used.

### **5. Victim Demographics**
Provides insights on victim age groups, gender, and descent.

### **6. District & Area Insights**
Highlights crime-prone districts and areas with detailed counts.

## 📦 How to Use

1. Download the `.pbix` file from the repository.  
2. Open it using **Power BI Desktop**.  
3. Refresh the dataset if required.  
4. Explore all visualizations and interact with slicers/filters.
